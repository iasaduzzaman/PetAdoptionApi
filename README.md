# 📘 Overview
**HR-Management** is a **Web API system** built to handle Human Resource operations efficiently.  
It allows organizations to manage:

✅ Employees  
✅ Departments  
✅ Attendance  
✅ Certifications  
✅ Requests  
✅ Skills  
✅ Roles & Authentication  

The system is designed for secure, scalable API communication and supports integration with any frontend (React, Angular, Vue, Flutter).

---

# ✅ Features
- 🔐 **JWT Authentication**
- 👥 **Employee & Department Management**
- 🎯 **Role-Based Access Control**
- 📝 **Leave & Request Handling**
- 📊 **Attendance Tracking**
- 📁 **File Upload & Download**
- 🗃 **Entity Framework + SQL Server**
- ✅ **Validation & Error Handling Middleware**
